Zero-Knowledge Secret Vault

Desafio Técnico

Armazenar e gerenciar credenciais ultra sensíveis no navegador sem nunca expor textos planos em disco ou servidores externos, garantindo imunidade a ataques de injeção e mantendo chaves derivadas estritamente isoladas na memória RAM com destruição automática por inatividade.

03 // SISTEMAS DE TEMPO & WEB APIS

Pomodoro Timer Pro

Desafio Técnico

Quando abas do navegador entram em segundo plano, temporizadores com setInterval sofrem throttling agressivo e perdem a sincronia exata dos segundos. Além disso, o usuário perde o controle visual do tempo ao alternar para outras aplicações de trabalho ou reuniões.

Estruturação de uma máquina de estados finita com cálculo contínuo de delta via objeto Date.now() (imune ao desvio do relógio) e integração com a recente Document Picture-in-Picture API, permitindo destacar um painel flutuante nativo sempre visível no sistema operacional, complementado por alertas sonoros via Web Audio API.

Tavern's Memory RPG

Desafio Técnico

Em jogos de memória baseados em eventos no DOM, cliques múltiplos e rápidos do jogador causam race conditions graves — abrindo 3 ou mais cartas simultaneamente e corrompendo a máquina de validação de pares —, além do desafio de renderizar rotações 3D fluidas a 60fps sem engines de jogos pesadas.

Solução Implementada

Implementação de um motor de jogo em JavaScript puro com padrão de bloqueio atômico (lockBoard), embaralhamento estatisticamente uniforme via Algoritmo Fisher-Yates, animações 3D nativas com transform-style: preserve-3d e persistência de histórico de pontuações via LocalStorage.

05 // SEGURANÇA CLIENT-SIDE & PIPELINE TEXTUAL

Markdown Previewer Suite

Desafio Técnico

Renderizar strings de Markdown digitadas pelo usuário diretamente em HTML pode abrir vetores críticos de vulnerabilidade Cross-Site Scripting (XSS via injeção de tags <script> ou handlers onerror). Além disso, a compilação contínua a cada digitação precisa ser fluida sem travar a thread principal da interface.

Solução Implementada

Criação de uma esteira segura de parsing cliente com Marked.js, filtrando estritamente todo nó gerado através do DOMPurify antes da injeção no DOM, sincronizando rascunhos em tempo real com LocalStorage e permitindo o download assíncrono do arquivo compilado via Blob API e Object URLs.

Vanilla JS ES6+ Marked.js Parser DOMPurify Security Blob URL Export LocalStorage CRUD

Sobre Sandro & Domínio de Fundamentos

Entender como a plataforma web funciona por baixo dos panos é a base para projetar qualquer sistema moderno e resiliente.

Engenharia Orientada a Fundamentos

Pragmatismo técnico, código sustentável e paixão pela Web Platform.

Sou estudante de tecnologia e desenvolvedor frontend focado na construção de sistemas web robustos, eficientes e esteticamente precisos. Minha filosofia de estudo é clara: antes de importar frameworks pesados ou bibliotecas mágicas, é essencial dominar profundamente como o navegador funciona — manipulação do DOM em nível fino, ciclo de renderização, Event Loop, APIs nativas e segurança client-side.

Cada uma das aplicações deste repositório foi concebida para resolver um desafio técnico específico de arquitetura cliente — unindo Engenharia de Software com Física Computacional e Web Platform (como análise sintática AST de esquemas SQL, criptografia autenticada AES-GCM de conhecimento zero, mecânica quântica com Crank-Nicolson O(N), traçado vetorial de raios luminosos com ótica de Snell-Cauchy e integração simplética Velocity Verlet para sistemas gravitacionais de N-corpos a 60 FPS).
