# Flashcards

Uma aplicação web interativa projetada para auxiliar no estudo e memorização através de flashcards. Este projeto combina funcionalidades de anotação com dinâmicas de quiz.

## Funcionalidades Principais
- **CRUD Completo:** Criação, leitura e exclusão de cartões.
- **Interatividade 3D:** Efeito de flip (virar) construído puramente com CSS para revelar as respostas.
- **Persistência Local:** Os cartões criados ficam salvos no `localStorage` do navegador, não se perdendo ao atualizar a página.

## Tecnologias Utilizadas
- HTML5 (Semântico)
- CSS3 (Variáveis, Grid, Transformações 3D)
- JavaScript Vanilla (Manipulação de DOM, Eventos, LocalStorage)

## Como rodar localmente
1. Clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno. Não é necessário nenhum build de servidor.
