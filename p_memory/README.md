# Tavern's Memory (RPG Memory Game)

Um Jogo da Memória interativo com temática Dark Fantasy/RPG. Este projeto demonstra controle de estado complexo, manipulação de DOM e lógica assíncrona em JavaScript puro.

## Funcionalidades Principais
- **Engine de Match & Lock:** Prevenção de *race conditions* garantindo que apenas duas cartas sejam viradas e avaliadas por vez.
- **Tracking de Desempenho:** Contabilização em tempo real de tempo decorrido e total de movimentos.
- **Game Loop Completo:** Algoritmo de Fisher-Yates para embaralhamento aleatório a cada nova partida e tela de vitória dinâmica.

## Tecnologias Utilizadas
- HTML5
- CSS3 (Transformações 3D e CSS Grid)
- JavaScript Vanilla (Eventos, `setInterval`, `setTimeout`, Lógica de Arrays)
