# Markdown Notes App

Um aplicativo de anotações baseado em navegador projetado para criar, ler, atualizar e excluir notas de forma rápida e eficiente.

## Funcionalidades Principais
* **CRUD Completo:** Criação, leitura, edição e exclusão de anotações.
* **Persistência de Dados:** As notas são armazenadas no `localStorage` do navegador, não se perdendo ao atualizar ou fechar a aba.
* **Suporte a Markdown:** Escreva em Markdown e visualize em HTML formatado automaticamente.
* **Carimbo de Data:** A data de criação é registrada e exibida em cada nota.

## Tecnologias Utilizadas
* HTML5 Semântico
* CSS3 (Grid/Flexbox)
* JavaScript Puro (Vanilla JS)
* API nativa de LocalStorage
* [Marked.js](https://marked.js.org/) para parsing de Markdown

## Como Executar
Este projeto não requer servidor back-end ou processos de build.
1. Clone este repositório.
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno.
