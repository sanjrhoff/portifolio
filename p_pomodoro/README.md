# Pomodoro Timer Pro

Um gerenciador de tempo robusto baseado na técnica Pomodoro, desenvolvido para maximizar a produtividade e o foco.

## Funcionalidades Principais
* **Ciclo Automático:** Alterna automaticamente entre sessões de Foco (25m), Pausa Curta (5m) e Pausa Longa (10m).
* **Gerenciamento de Estado:** Acompanha quantas sessões de foco foram concluídas. A cada 4 sessões, uma pausa longa é acionada.
* **Customização Total:** Permite configurar os tempos de cada etapa antes de iniciar.
* **Feedback Visual e Sonoro:** A interface altera seu esquema de cores com base no status atual, e um alarme sonoro é disparado ao final de cada contagem.

## Tecnologias Utilizadas
* HTML5 Semântico
* CSS3 (Transições Dinâmicas)
* JavaScript Puro (Vanilla JS) com manipulação do Objeto `Date` e `setInterval`.

## Como Executar
1. Clone o repositório.
2. Abra o arquivo `index.html` em seu navegador web (pode utilizar um servidor local como XAMPP ou Live Server se preferir).
