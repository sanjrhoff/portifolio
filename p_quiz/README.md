# Quiz Master Pro

Um aplicativo completo de perguntas e respostas com sistema de autenticação simulado e histórico de pontuações.

## Funcionalidades Principais
* **Sistema de Contas:** Crie um "usuário" (simulado via `localStorage`) para manter um painel pessoal.
* **Múltiplos Quizzes:** Escolha entre diferentes temas para testar seus conhecimentos.
* **Feedback Imediato e Progresso:** Barra de progresso visual e destaque de acertos/erros em tempo real.
* **Cálculo Estatístico:** Tela final avalia o tempo total gasto e calcula a taxa de aprovação (Corte de 60%).
* **Compartilhamento Web:** Gera um link automático para compartilhar a vitória no Twitter/X.

## Tecnologias Utilizadas
* HTML5 (Manipulação dinâmica de telas baseada em ID)
* CSS3 (Animações chave, layout dinâmico)
* JavaScript Puro (Objeto literal para banco de dados, `Date.now()` para cronometragem precisa).
